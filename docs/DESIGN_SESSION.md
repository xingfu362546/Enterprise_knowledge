# 企业知识库 · 设计决策

## 智能助手

- 名称：**小Q**
- 能力：检索企业制度、部门 SOP、岗位规则；回答附带文档引用（原型为模拟数据）

## 入口方案

| 端 | 方案 |
|----|------|
| PC 门户 | 右下角橙色胶囊 FAB + 引导气泡 → 右侧抽屉聊天 |
| 小程序 | 卡通形象小Q浮于首页右下，8s 后缩至边缘；点击进 `kb-chat.html` |
